# Portfólio Pessoal de Marcio Gil

## Visão Geral

Este projeto é um portfólio pessoal em HTML/CSS/JavaScript criado para apresentar projetos, experiência e habilidades de forma clara, moderna e responsiva. O objetivo é proporcionar uma presença profissional online simples e eficiente, com navegação fluida e destaque para o trabalho realizado.

## Objetivo do Projeto

- Mostrar projetos pessoais e profissionais.
- Apresentar habilidades e tecnologias dominadas.
- Fornecer um canal de contato direto.
- Ter um design responsivo, compatível com desktop e mobile.
- Ser leve e fácil de manter.

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (opcional para interações)
- Layout responsivo com Flexbox e/ou Grid
- Ícones e fontes web (por exemplo, Font Awesome ou Google Fonts)

## Seções Principais do Portfólio

1. **Home / Apresentação**
   - Nome completo e profissão
   - Frase de apresentação ou slogan
   - Foto ou avatar profissional

2. **Sobre Mim**
   - Resumo curto sobre formação e perfil
   - Valores, missão e estilo de trabalho

3. **Habilidades**
   - Tecnologias principais
   - Ferramentas e linguagens
   - Competências técnicas e pessoais

4. **Projetos**
   - Lista de projetos com descrição
   - Links para demo ou repositório
   - Tecnologias utilizadas em cada projeto

5. **Experiência / Educação**
   - Histórico profissional ou acadêmico
   - Atividades relevantes

6. **Contato**
   - Email, telefone, redes sociais e/ou formulário de contato
   - Link para download de currículo, se houver

## Como Executar Localmente

1. Clone este repositório:

```bash
git clone https://github.com/<seu-usuario>/portfolio_marcio_gil_v2html.git
cd portfolio_marcio_gil_v2html
```

2. Abra o arquivo `index.html` no navegador.

3. Se desejar usar um servidor local, execute um servidor simples (exemplo com Python):

```bash
python -m http.server 8000
```

4. Navegue até `http://localhost:8000`.

## Personalização do Portfólio

- Atualize `index.html` com seu nome, bio e links.
- Ajuste `css/style.css` para refletir sua paleta de cores e identidade visual.
- Substitua imagens e ícones em `assets/imagens/`.
- Se houver `js/main.js`, adicione animações, menu móvel ou efeitos de scroll.
- Inclua novos projetos na seção de projetos, mantendo a organização clara.

## Recomendações de Design

- Use tipografia legível e espaçamento consistente.
- Mantenha o design simples e profissional.
- Priorize conteúdo relevantes mais acima na página.
- Teste em telas pequenas e grandes para validar o layout responsivo.

## Deploy

O portfólio pode ser publicado facilmente em plataformas como:

- GitHub Pages
- Netlify
- Vercel
- Surge

### Exemplo com GitHub Pages

1. Faça commit e push para o repositório remoto.
2. Ative o GitHub Pages nas configurações do repositório.
3. Escolha a branch `main` ou `gh-pages` como fonte.
4. Acesse o site gerado pelo GitHub.
